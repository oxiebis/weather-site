# Сайт погоди 
  
Навчальний проєкт для практичних робіт Модуля 3 
(DevOps Basic). Дані про погоду згенеровані штучно 
та використовуються лише для навчальних цілей. 
  
## Структура - index.html — головна сторінка - style.css — стилі оформлення - script.js — логіка відображення даних - data/weather.json — згенеровані дані погоди
