# Сайт погоди — v1.0

Навчальний проєкт для практичних робіт Модуля 3 (DevOps Basic).
Дані про погоду згенеровані штучно та використовуються лише для навчальних цілей.

## Структура
- index.html — головна сторінка
- css/style.css — стилі оформлення
- js/script.js — логіка відображення даних
- data/weather.json — згенеровані дані погоди

## Історія розробки
Проєкт створено та розвинуто в межах практичних робіт ПР 3.1–3.4 курсу DevOps Basic.
